# Student Score Prediction using Machine Learning

## Project Overview
This project predicts student scores based on study hours using the Linear Regression algorithm.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset
student_scores.csv

## Steps
1. Load the dataset
2. Clean the data
3. Split the data
4. Train the model
5. Predict scores
6. Evaluate the model

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score
